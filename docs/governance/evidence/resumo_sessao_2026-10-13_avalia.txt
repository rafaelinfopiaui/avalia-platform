DESVIO FINAL — DIAGNÓSTICO DO BUG DE AUTENTICAÇÃO DO CLAUDE CODE
================================================================================
(Somente diagnóstico; nada foi alterado/apagado/renomeado nesta sessão.)

Causa provável: dois processos Claude Code concorrentes, de origens diferentes,
disputando a mesma sessão OAuth e persistindo credenciais em backends
diferentes (Keychain do macOS vs. arquivo ~/.claude/.credentials.json). Como o
refresh token é rotativo, cada refresh de um processo invalida o do outro —
explicando a queda intermitente de login.

Evidências principais:
  - Após um único login, Keychain e arquivo tinham tokens DIFERENTES
    (refresh e access distintos), com ~66s de diferença de expiração.
  - Processo PID 49429 (extensão Claude Code do Antigravity IDE, versão
    2.1.292 desatualizada) rodando em segundo plano desde antes do login —
    origem provável do refresh concorrente.
  - Duas versões da extensão instaladas (2.1.292 e 2.1.296), rodando a antiga.
  - CLI standalone separada e atualizada (2.1.299) em ~/.local/bin/claude.

Correção recomendada (não executada nesta sessão): encerrar o processo zumbi,
renomear .credentials.json para .bak, fazer claude auth login uma vez com tudo
fechado, reabrir o Antigravity na versão nova, e monitorar se o arquivo
reaparece. (Observação: esta correção foi efetivamente aplicada depois, já em
sessão posterior.)
